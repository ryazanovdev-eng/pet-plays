[Демо](../../demo/index.html) открывается с диска. Это представление двух положений камеры и галерея арта, а не управляемый забег. Blender-пилот исключён из показа.

| Что проверено | Результат |
|---|---|
| Карта | Две камеры в `game/arena.tscn` и `game/arena_edge.tscn` инстанцируют один `game/arena_parts/world.tscn`. Центры (2390,1700) и (3450,640), оба кадра 1280×720 при одном масштабе. Ограждённая область занимает 4320×2500 по крайним точкам. По четыре физических луча из каждого вида попали в `Perimeter`. В центральном кадре граница не видна, в краевом видны стена и объекты за ней |
| Интерфейс | Портрет игрока, его HP с числом и уровень слева сверху; номер волны по центру, кости рядом с ним. У босса только шкала. Панель управления слева снизу, миникарта справа снизу. Просмотр по кадрам Godot, числовые значения статические |

Полупрозрачность при получении урона и затухании призраков сохранена. 248 файлов в `demo/media/frames/` проверены на побайтовое совпадение с производственными ресурсами |

Надпись над витражом и полоса над крышей склепа с черепом отсутствуют на новом рендере. Превью для браузера сохраняются без потерь |
