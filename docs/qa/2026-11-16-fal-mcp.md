# Проверка fal MCP

- **Дата:** 2026-11-16
- **Пакет:** `fal-mcp-server` 1.18.0
- **Python:** 3.11 (managed by uv)
- **Статус:** проверен на реальной генерации; `get_usage` недоступен без admin-ключа

## Итог

MCP-сервер fal.ai работает с настоящим ключом. Первый запуск падал из-за несовместимости: пакет использует старый API `mcp`, а uv ставил `mcp 2.3.0`. Ограничение `--with "mcp<2"` решило проблему.

Проверено на реальной задаче: сгенерировано изображение скелета-солдата, по нему собрана low-poly модель с ригом и анимацией `Walk`, модель импортирована в Godot.

`fal_get_usage` вернул `Access denied`: обычный ключ не имеет прав на просмотр расходов, нужен admin-ключ. Поэтому стоимость ниже посчитана по прайсу.

## Стоимость теста

- 512 × 512 = 0.262144 МП.
- 0.262144 × $0.003 = **$0.000786432**.
- Округлённо: **≈ $0.0008** (меньше 0.1 цента).
- Локальная 3D-модель и анимация: **$0**.
- Итого за тест: **≈ $0.0008**.
- Остаток от лимита $5: **≈ $4.9992**, но точный расход нужно смотреть в биллинге fal.

`fal_get_usage` недоступен с текущим ключом. Если нужен точный программный учёт, создать admin-ключ или смотреть Usage в кабинете fal.
