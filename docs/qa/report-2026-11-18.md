# M3: визуальная демонстрация Frog Knight

Ветка `feature/art`, Godot 4.7.2, GL Compatibility, кадр 1280×720. Проверяется витрина арта, не игровой баланс. Художественное утверждение остаётся за автором проекта.

| Проверка | Что проверено |
|---|---|
| Каст | 12 сцен `AnimatedSprite2D`, 62 последовательности по 4 кадра, у боссов отдельные `attack1` и `attack2`. Проверены прозрачность, порядок, размеры, привязки стоп, частоты и режимы повторения. Пустых кадров нет. Затухание призраков в `death` намеренное |
| Основная арена | На кадре из Godot видно замкнутую ограду, героя и Гнилого гиганта на дорожке, три типа подбора, здоровье, опыт, волну и валюту. Фоновые движения воспроизводятся, позы центральной схватки зафиксированы. Коллизии и бой не входят в этот этап |
| Гибрид | Из Godot снята сцена с ортокамерой, 3 персонажами и 7 типами объёмных пропсов из Blender. Это тест барельефов с рисованным лицевым слоем для одного ракурса, а не полноценные модели для свободно вращаемой камеры |
| Каталог | Все 15 предметных листов отрисованы движком. При просмотре первого листа найдены и очищены примеси соседних рисунков в трёх PNG: `crypt_small_glowing`, `stump`, `twisted_tree`. Размеры и точки опоры не менялись |
| Целостность | Проверены внешние ссылки текстовых ресурсов `game/` и `assets/`: ни одна не требует `raw/`. Оригиналы нужны только для повторной подготовки арта. Локальные Markdown-ссылки README и документации разрешаются |
| Браузер | `node tools/check_demo.mjs` открывает `demo/index.html` по `file://` в Edge: декодирует изображения, переключает 12 персонажей, 62 клипа, три записи сцен и 15 предметных листов, проверяет покадровый шаг и ширину страницы при 375 px |

**Правки после просмотра:** в семи кадрах боссов очищены полосы, чужие фрагменты плаща и преждевременные брызги; у Костяного короля в `death/03` восстановлено острие меча из исходного рисунка. Холсты и точки привязки не менялись. Производные файлы повторно импортированы в Godot и экспортированы для браузера.

**Фактический вывод проверок:** `OK: импорт и запуск главной сцены прошли без ошибок.`; `PASS { actors: 12, clips: 62, views: 3, sheets: 15 } offline desktop + mobile`.

Для повторения: `.\tools\check.cmd`, `python tools/build_demo.py`, `node tools/check_demo.mjs`. Для визуального сравнения откройте [демо](../../demo/index.html), затем [эталоны](../art/README.md). В записи арены рассматривайте масштаб и читаемость, в бестиарии отдельно проверьте замахи обоих боссов, в гибриде сравните плоских бойцов с толщиной стен и камня.
