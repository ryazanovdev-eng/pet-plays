## Найдено и исправлено

1. **`mcp` лежал внутри `permission`.** Kilo ищет серверы в корне конфига. Блок перенесён на верхний уровень.
2. **`uvx` не был в PATH.** В конфиге теперь полный путь к `uvx.exe` из winget-пакета.
3. **`add_node` не принимает `res://`.** `create_scene` принимает `res://game/scene.tscn`, а `add_node` ждёт `game/scene.tscn`. Это записано в `docs/05-mcp.md`.

## Риски

- Blender MCP выполняет Python внутри Blender. Включён `BLENDER_MCP_SAFE_MODE=1`, но перед экспериментами нужно сохранять `.blend`.
- Godot MCP меняет `.tscn`. Перед изменениями сцен делать коммит.
- Путь к `uvx.exe` привязан к winget-пакету. При переустановке uv путь может измениться.
