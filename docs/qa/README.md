# Проверки

Отчёты за 15–16 ноября описывают исторические пробы MCP, камеры и cutout-рига. Их выводы и разделы «Дальше» не относятся к нынешней поставке. Для M3 критерии перечислены в [плане](../04-plan.md); результат фиксируется только после фактического просмотра.

Отчёты QA лежат здесь: `report-YYYY-MM-DD.md`.

## Серьёзность

- **blocker** — игра не запускается или теряются данные.
- **major** — механика не работает по GDD.
- **minor** — косметика, текст, удобство.

## Минимум для отчёта

- дата, ветка, версия Godot;
- что проверяли и по какому критерию;
- шаги воспроизведения;
- ожидаемое и фактическое поведение;
- фактический вывод `.\tools\check.cmd`.
