# Концепт-арт

## Папки

- `raw/` — черновые генерации. В git не попадают (см. `.gitignore`).
- `approved/` — отобранные концепты. Хранятся в git.

## Именование

```
raw/20261115-193000-cat-courier-s123456.jpg
raw/20261115-193000-cat-courier-s123456.jpg.json
```

Рядом с каждым изображением лежит `.json` с промтом, сидом, моделью и размером. Это нужно, чтобы повторить или улучшить результат.

## Как отбираем

1. Генерируем 3–6 вариантов с разными сидами.
2. Смотрим в игровом масштабе, а не только в полном размере.
3. Отмечаем удачные в `docs/03-art-bible.md`.
4. Копируем принятое в `approved/` и фиксируем в арт-библии.
