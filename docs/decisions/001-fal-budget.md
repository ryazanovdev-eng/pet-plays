# ADR-001: Лимит fal.ai — 5 долларов на проект

- **Дата:** 2026-11-16
- **Статус:** принято
- **Контекст:** fal.ai работает по предоплаченным кредитам. Ошибка в промте или запуск дорогой модели может быстро съесть баланс.
- **Решение:** на весь проект pet-plays — не больше **$5** на fal.ai. Перед платной генерацией агент проверяет цену через `fal_get_pricing`, после — расход через `fal_get_usage`. Дорогие модели (видео, Meshy, 3D) запускаются только с явного согласования.
- **Альтернативы:** жёсткий лимит в кабинете fal (если доступен) — дополнительная страховка; локальная генерация — дороже по времени, но бесплатна.
- **Последствия:** при приближении к $5 генерация останавливается и пользователь решает, поднимать ли лимит. Лимит — политика проекта, а не техническое ограничение MCP.
