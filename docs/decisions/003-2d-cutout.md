# ADR-003: 2D-кукла на костях вместо 3D-пререндера

- **Дата:** 2026-11-16
- **Статус:** исторический пилот; не действующая инструкция. Текущий процесс: [покадровый арт](../06-asset-pipeline.md).
- **Контекст:** 3D-пилот (примитивы, toon + контур) не дал вида C «Painted storybook»: шлем закрывал голову, руки/меч/шарф не читались, окружение выглядело как серые прямоугольники. Пользователь выбрал 2D-куклу на костях, чтобы сохранить рисованный вид C. ADR-002 (2D-спрайты из 3D-пререндера) в части производства отменяется.
- **Решение:**
  1. В игре — **2D-персонаж-кукла**: части нарисованы в стиле C, собраны в Godot на `Skeleton2D`/`Bone2D` (спрайты на костях); 3D в рантайме и на производстве персонажей не используется.
  2. Для вертикального среза — **один 3/4-вид + горизонтальный флип**. 4 или 8 направлений не делаем, пока не будет доказано, что без них плохо.
  3. Арт-производство: лист персонажа в **A-позе** (руки/ноги разведены, чистый фон) → нарезка на 12–14 частей → чистка стыков → риг в Godot. AI (fal) — для листа и фона; нарезка/чистка — вручную.
  4. Окружение — 2D-спрайты: надгробия proper shapes, пучки травы, забор, деревья; кость-лут из стилевого кадра убираем.
  5. Вертикальный срез и бюджет fal **$5** не меняются.
- **Альтернативы:** довести 3D-модель (дороже по качеству, всё равно «3D-игрушка»); покадровая 2D-анимация (дороже по времени).
- **Последствия:** персонаж будет ближе к C; анимации — вращение костей, без 3D-рендера. Появятся ручные стыки (плечи, локти, бёдра, колени), их закрываем нахлёстом и подрисовкой. Направлений меньше, зато сроки реальные.
