# ADR-002: 2D-визуал из 3D-пререндера и вертикальный срез

- **Дата:** 2026-11-16
- **Статус:** исторический пилот; не действующая инструкция. Текущий процесс: [покадровый арт](../06-asset-pipeline.md).
- **Контекст:** пользователю нравятся 2D-иллюстрации Cult of the Lamb, Don't Starve Together, Wytchwood и тёплый top-down пример с чётким контуром. В GDD зафиксирован 2.5D low-poly, но финальный вид хочется более рисованный. Генерация покадровых спрайтов нейросетью даёт разнобой, а ручная 2D-анимация для 102 врагов не влезает в сроки.
- **Решение:**
  1. В игре — **2D-спрайты** с толстым контуром; фон — живописный.
  2. Производство персонажей и анимаций — **3D low-poly → toon-материал + контур → рендер кадров с фиксированных углов → спрайт-атлас**. 3D используется только на этапе производства, не в рантайме.
  3. fal.ai — только концепт-арт, фон арены, иконки и промо. Покадровые анимации через fal не делаем.
  4. Первый прототип — **вертикальный срез**: одна арена, рыцарь-лягушка, 2 типа врагов по 1 варианту, 1 босс, 3 волны. Полный контент GDD (6 вариантов врагов, 2 босса, 5 волн) остаётся целью после среза.
  5. Бюджет fal.ai не меняется: **$5** на проект (ADR-001).
- **Альтернативы:** чистая ручная 2D-анимация (дорого по времени); 3D low-poly в рантайме (дешевле, но не тот вид); AI-видео для анимаций (дорого и нестабильно).
- **Последствия:** нужен рендер-пайплайн и спрайт-атласы; анимации детерминированы и консистентны. Сроки растут за счёт 2D-вида и вертикального среза. GDD не отменяется, но M4-план сначала ведёт к срезу. Числа и критерии полного GDD остаются ориентиром для финальной версии.
