# Anarchist Frog Knight · pet-plays

Аркада на одном кладбище для Godot 4.7.2. **M3 на повторной визуальной приёмке; M4 не начат.** Предмет показа — арт, не играбельный забег.

| Где смотреть | Что сравнить |
|---|---|
| `game/arena.tscn` | Центр кладбища: открытое место для боя, предметы и HUD. В кадре только часть карты |
| `game/arena_edge.tscn` | Край той же многоэкранной карты: вблизи видна ограда, но не весь периметр |
| `game/gallery.tscn` | Герой, девять врагов, два разных босса и их движения |
| `demo/index.html` | Браузерная демонстрация |

**Посмотреть демо:** откройте [demo/index.html](demo/index.html) в браузере. Сначала сопоставьте центр и край одной ограждённой карты, затем откройте галерею движений. Для передачи демо нужна вся папка `demo/`.

**Открыть исходную сцену:** в редакторе (`.\tools\godot.cmd -Editor`) откройте нужный `.tscn` из таблицы и нажмите F6. Листы атласа лежат в `game/arena_inventory/`. Blender не используется в демо: исходник отклонённого пилота `assets_src/hybrid/vesper_court.blend` сохраняется только как архив.

**Обновить витрину после правок:** `.\tools\check.cmd`, затем `python tools/build_demo.py` (Godot и Pillow). Страница получает кадры сцен через Godot Movie Maker, а последовательности персонажей из `SpriteFrames`; игровых скриптов у сцен нет. `node tools/check_demo.mjs` проверяет готовую витрину в Edge; путь к другому Chromium можно указать в `EDGE_BIN`.
