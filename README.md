# pet-plays

Небольшая игра на Godot 4.7.2 (GDScript). Пет-проект.

## Быстрый старт
```powershell
.\tools\godot.cmd -Editor   # открыть редактор
.\tools\godot.cmd           # запустить игру
.\tools\check.cmd           # headless-проверка проекта
```

## Пайплайн
Концепт → арт → план → разработка. Подробности: [docs/00-pipeline.md](docs/00-pipeline.md).

## MCP
Blender и Godot подключены через MCP. fal.ai настроен и ждёт токен в глобальном конфиге. Настройка и проверка: [docs/05-mcp.md](docs/05-mcp.md).
