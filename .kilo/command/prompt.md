Сохрани промт в библиотеку проекта: $ARGUMENTS

1. Определи категорию: image, model3d, animation, audio, ui, texture.
2. Делегируй подагенту `prompt-smith` через Task: создать `docs/prompts/<category>-<slug>.md` по шаблону `_template.md`.
3. Для изображений обязательно добавь style anchor, негатив, модель, размер и сид.
4. Для 3D — требования к turnaround и позе. Для анимаций — сетку кадров и fps. Для аудио — темп, инструменты, зацикленность.
5. Обнови индекс в `docs/prompts/README.md`.
6. Покажи путь к файлу и одной строкой — для чего он.

Если не хватает деталей, задай не больше двух вопросов.
